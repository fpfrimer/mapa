# Mapa de Horários Acadêmicos

Aplicação front-end simples para construir cronogramas semanais de cursos.

## Como usar

1. Abra o arquivo `index.html` em um navegador moderno (Chrome, Edge, Firefox).
2. Cadastre períodos, professores, salas e disciplinas pelo painel lateral.
3. Selecione a visão desejada (por período, professor ou sala) e escolha o item para visualizar.
4. Clique em um bloco do cronograma para atribuir/editar uma disciplina.
5. O painel de edição sugere professores e salas livres naquele horário, evitando conflitos entre os mapas.

As informações ficam armazenadas apenas na memória do navegador.
